# Training Schedule Management

## Project Overview

The Training Schedule Management System is a C++ based application developed to manage and organize training schedules efficiently.

This project allows administrators and faculty members to manage training sessions, allocate trainers, and maintain schedule records in a structured way. The system is designed using Object-Oriented Programming principles and structured project architecture.

---

## Features

- Admin login functionality  
- Faculty login functionality  
- Trainer allocation management  
- Training schedule management  
- File-based data storage using CSV files  
- Modular design with separate header and source files  

---

## Technologies Used

- C++
- CMake
- Make
- CSV File Handling
- Object-Oriented Programming (OOP)

---

## Project Structure

- `src/` – Source files  
- `include/` – Header files  
- `data/` – CSV data files  
- `docs/` – Documentation files  
- `UML Diagrams/` – System design diagrams  

---

## How to Run

1. Install CMake, Make, and a C++ compiler.
2. Navigate to the project directory.
3. Create a build folder and compile the project:

```bash
mkdir build
cd build
cmake ..
make
```

4. Run the application:

For Windows:
```bash
app.exe
```

For Mac/Linux:
```bash
./app
```
